TEMUAN KRITIS (CRITICAL)

1. CSRF Token Terekspos di Client-Side

Severity: CRITICAL
CVSS Score: 9.1
Location: Lines ~1150, ~1250

'X-CSRF-TOKEN': 'ZKDOAAR2BTWrpVID7y1pK63UjnH6RvfeZmaC6SO3'

Dampak:

  • Token CSRF yang seharusnya rahasia terekspos di source code
  • Attacker dapat melakukan CSRF attack dengan mudah
  • Session hijacking dan unauthorized actions

Rekomendasi:

  • Generate CSRF token dinamis per session
  • Simpan token di secure HTTP-only cookie
  • Jangan pernah hardcode token di JavaScript

2. Cross-Site Scripting (XSS) - DOM Based

Severity: CRITICAL
CVSS Score: 8.8
Location: Lines ~1100, ~1200

document.getElementById('trackModalBody').innerHTML = html;

Dampak:

  • Attacker dapat inject malicious JavaScript
  • Data dari API response langsung di-render tanpa sanitasi
  • Session theft, defacement, malware distribution

Rekomendasi:

// Gunakan textContent atau sanitasi HTML
function escapeHtml(text) {
    const map = {
        '&': '&amp;',
        '<': '&lt;',
        '>': '&gt;',
        '"': '&quot;',
        "'": '&#039;'
    };
    return text.replace(/[&<>"']/g, m => map[m]);
}

TEMUAN TINGGI (HIGH)

4. Missing Security Headers

Severity: HIGH
CVSS Score: 7.0

Headers yang Hilang:

❌ Content-Security-Policy (CSP)
❌ X-Frame-Options
❌ X-Content-Type-Options
❌ X-XSS-Protection
❌ Strict-Transport-Security (HSTS)
❌ Referrer-Policy
❌ Permissions-Policy

Rekomendasi:

<meta http-equiv="Content-Security-Policy" 
      content="default-src 'self'; script-src 'self' 'unsafe-inline' cdn.jsdelivr.net cdn.tailwindcss.com; style-src 'self' 'unsafe-inline' cdnjs.cloudflare.com; img-src 'self' data: https:; font-src 'self' cdnjs.cloudflare.com;">

5. Insecure External Dependencies

Severity: HIGH
CVSS Score: 6.8

CDN yang Digunakan:

<script src="https://cdn.tailwindcss.com"></script>
<script src="https://cdn.jsdelivr.net/npm/alpinejs@3.x.x/dist/cdn.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/sweetalert2@11"></script>
<link href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.0.0/css/all.min.css" rel="stylesheet">

Risiko:

  • Supply chain attack
  • CDN compromise
  • Man-in-the-Middle (MITM)
  • Version tidak spesifik (menggunakan x.x.x)

Rekomendasi:

  • Gunakan Subresource Integrity (SRI)
  • Pin specific version
  • Host critical libraries secara lokal
<script src="https://cdn.jsdelivr.net/npm/sweetalert2@11.7.32" 
        integrity="sha384-..." 
        crossorigin="anonymous"></script>

6. Insufficient Input Validation

Severity: HIGH
CVSS Score: 7.2

function trackPengaduan() {
    const noPengaduan = document.getElementById('trackPengaduanInput').value.trim();

    if (!noPengaduan) {
        // Hanya validasi empty
    }
}

Risiko:

  • SQL Injection
  • NoSQL Injection
  • Command Injection
  • Buffer Overflow

Rekomendasi:

// Validasi format nomor pengaduan
const pattern = /^[A-Z0-9\-\/]+$/;
if (!pattern.test(noPengaduan) || noPengaduan.length > 50) {
    throw new Error('Invalid input format');
}
